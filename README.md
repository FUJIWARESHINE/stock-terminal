# QUANTA 智能行情终端

Windows 桌面股票终端，集成股价走势、市场热点、自选聚焦与基金分析。

## 功能

### 行情走势
- K 线图（日 / 周 / 月 / 15 / 30 / 60 分钟）、分时图、5 日分时
- MA5 / MA10 / MA20 / MA60 均线与成交量柱，支持缩放与十字光标
- 实时报价：价格、涨跌幅、开盘 / 最高 / 最低 / 昨收、振幅、换手、成交额、主力净额、总市值
- 顶部大盘指数条：上证、深证、创业板、科创 50、沪深 300

### 热点资讯
- 行业 / 概念板块热度榜，含涨跌幅、主力净额与领涨股
- 涨幅榜、跌幅榜、主力资金流排行
- 7×24 财经快讯、要闻、股市资讯流，点击可跳转原文

### 自选聚焦
- 搜索股票加入聚焦池，卡片展示实时价、涨跌与迷你走势图
- 多只自选股归一化收益对比曲线（近 1 月 / 3 月 / 6 月 / 1 年）
- 自选本地保存，重启自动恢复，右键或卡片 × 移出

### 基金中心
- 基金净值走势（近 1 月 / 3 月 / 6 月 / 1 年 / 成立以来），自动标注最高最低
- 阶段收益：近 1 周 / 1 月 / 3 月 / 1 年 / 今年来 / 成立来
- 基金排行：全部 / 股票型 / 混合型 / 债券型 / 指数型 / QDII，支持自选基金

## 使用

1. 双击 `QUANTA.exe` 启动。
2. 右上角搜索框输入股票或基金的名称 / 代码，点击下拉结果即可加入聚焦并查看。
3. 主图下方「+ 加自选」加入聚焦池，左侧自选列表右键可移出。
4. 顶部标签页切换：行情走势 / 热点资讯 / 自选聚焦 / 基金中心。

行情数据来自公开行情接口，自选数据保存在本机 `%APPDATA%\StockTerminal`。
所展示数据可能存在延时，仅供行情查看与技术分析，不构成投资建议。
